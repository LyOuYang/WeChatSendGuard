# 安全与隐私边界

- 应用只观察前台受信任目标客户端，并只读取识别会话标题、会话类型和编辑框焦点所需的公开无障碍元数据。
- 信任基于确定性的目标客户端身份，不基于宽泛的进程名匹配。Windows `1.2.0` 使用默认或用户保存的精确 `Weixin.exe` 路径。
- 路径不匹配、查询失败、UI 元素过期、权限级别不一致、客户端界面不兼容或重新校验不一致时，应用绝不注入发送键。
- 合成输入使用标记，键盘钩子不会把自身的注入事件当作物理输入再次处理。
- 草稿预览是可选的、仅在内存中存在，并且只属于一个确认窗口；不会持久化或写入日志。
- 审计记录刻意最小化：只含时间、受保护会话 ID、匿名链路 ID、事件类型、结果和必要环境版本；不含消息、草稿、会话名称或用户目录。日志按天轮转、单文件最多 1 MiB、总量最多 50 MiB，并按用户选择的 1–30 天自动清理。
- 设置和审计数据只保存在当前用户的本地应用数据目录。
- 除更新功能外，应用不使用网络服务、遥测管道、客户端数据库访问、代码注入、屏幕截图、剪贴板捕获或远程控制。
- 自动更新默认开启，但可在“关于”页关闭；检查时仅通过 HTTPS 请求 GitHub Releases 的公开版本元数据，不上传消息、会话、日志、设置或任何标识数据。
- 下载更新只能由用户在“关于”页明确发起。安装包必须与同一 GitHub Release 中的 SHA-256 校验文件匹配，否则应用删除临时文件并拒绝启动安装程序。忽略某版本只抑制自动提醒，不会隐藏该版本的手动升级入口。
