## 更新内容

### Windows
- 新增/改进：确认窗口现在从原始微信编辑框读取草稿预览，并在 ValuePattern 为空时回退到 TextPattern。
- 修复：避免确认窗口接管前台后错误丢弃草稿预览，并补充预览结果审计记录。
- 兼容性与验证：Windows 安装器支持附加构建标识；自动化测试覆盖草稿预览和服务逻辑，真实微信兼容性按人工验证清单确认。

### macOS
- 新增/改进：调整主窗口和确认窗口的布局、边框及状态显示，改善不同确认方式下的窗口尺寸计算。
- 修复：优化确认窗口相对微信窗口的居中定位，并保留缩放比例下的尺寸回退处理。
- 兼容性与验证：提供 Universal DMG，使用 Ad-hoc 签名且未公证；真实微信兼容性按人工验证清单确认。

### 已知问题
- Beta 与稳定版当前共用安装身份，不支持并行安装。
