## 更新内容

### Windows
- 新增/改进：支持从托盘对当前已识别会话临时放行 1、5 或 15 分钟，且不修改保护名单。
- 修复：优化当前会话状态、临时放行失败提示，以及设置和暂停/恢复的审计记录。
- 兼容性与验证：自动化测试覆盖临时放行和保护决策；真实微信兼容性按人工验证清单确认。

### macOS
- 新增/改进：共享核心规则支持当前会话临时放行，且不修改保护名单；同步改善状态反馈。
- 修复：补充设置、暂停/恢复和临时放行的审计记录，优化界面状态文案。
- 兼容性与验证：提供 Universal DMG，使用 Ad-hoc 签名且未公证；真实微信兼容性按人工验证清单确认。

### 已知问题
- Beta 与稳定版当前共用安装身份，不支持并行安装。
