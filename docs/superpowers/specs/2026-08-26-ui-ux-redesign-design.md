# Design Spec: WeChatSendGuard UI & UX Redesign

## 1. 概述与目标

针对 WeChatSendGuard（微信消息发送守护工具）进行视觉与交互重构。贯彻**“直觉驱动设计（Intuition-Driven Design）”**与**“微信原生亲和风格”**，减少说教式堆砌文字，通过卡片分块、色彩徽章、自解释控件与微动效，实现：
1. **0.1 秒认知**：弹窗弹出时瞬间认清“发给谁”与“发什么”；
2. **绝对防手滑**：800ms 平滑长按确认，松手即重置；
3. **配置逻辑内聚**：设置页三层分块，会话别名与列表项直接内联，规则卡片化。

## 3. 设置主界面 (MainWindow) 架构设计

### 3.1 布局分层
- **顶部 Header & Hero Bar**：
  - 应用标题：`WeChatSendGuard` + `微信发送守护`。
  - 右侧状态胶囊：实时展示微信连接状态（🟢 `守护中 · [群聊] 研发核心群` / ⚪ `微信未聚焦`）。
  - 主控卡片：`[✓] 启用发送保护` 大 Switch/CheckBox，搭配模式下拉框（`🛡️ 保护名单模式` / `⚡ 免确认白名单模式`）。
- **双栏工作区 (Split View)**：
  - **左栏 (46% 宽)：受保护会话管理**
    - 顶部统计：`守护会话 (共 X 个)`。
    - 丰富列表卡片：
      - 显示专属类型徽章：`[群聊]` 或 `[联系人]`。
      - 显示会话名称（粗体）。
      - 若有别名，在名称下方显示浅灰 `别名: xxx, yyy`。
      - 列表为空时提供简洁直观的 Empty State。
    - **别名内联条**：位于列表正下方，选中单项时直接展示与编辑别名输入框，未选中时自然置灰提示。
    - **操作栏**：
      - 主按钮：`➕ 加入当前微信会话`（微信在前台时高亮可用）。
      - 辅助按钮：`🗑️ 移除选中`、`📥 导入`、`📤 导出`。
  - **右栏 (54% 宽)：直觉卡片式规则配置**
    - **卡片 1【按键拦截】**：
      - `[✓] 主键盘 Enter`、`[✓] 小键盘 Enter`。
      - 辅助文字提示：`Shift+Enter 换行始终直接放行`。
    - **卡片 2【二次确认方式】**：
      - 确认方式下拉或单选：`长按确认 (推荐)`、`单击确认`、`输入确认词`。
      - 当选择“长按确认”时，显示 `按住时长: [ 800 ] ms`。
      - 当选择“输入确认词”时，显示 `确认词: [ 发送 ]`。
      - 弹窗超时：`自动取消: [ 10 ] 秒`。
    - **卡片 3【系统策略】**：
      - 微信未识别时行为下拉框：`[ 要求确认 ▾ ]`。
      - `[✓] 随 Windows 启动`、`日志保留: [ 7 ] 天`。
- **底部状态栏**：
  - 左侧：`💡 名单修改即时生效 · 其它配置点击保存后生效`。
  - 右侧：`[ 保存设置 ]` 醒目微信绿主按钮。

## 4. 二次确认弹窗 (ConfirmationWindow) 交互设计

### 4.1 视觉层级
- 宽度 480px，卡片圆角 12px，纯白背景与精致外阴影。
- **Header**：`🛡️ 发送前确认` + `Esc 取消`。
- **第一视觉焦点【目标卡片】**：
  - 浅绿背景 (`#E8F8F0`)，粗体大号标题显示目标名称，配带 `[群聊]` / `[联系人]` 专属徽章。
- **第二视觉焦点【草稿内容气泡】**：
  - 仿微信聊天气泡卡片，限制最大高度，有内容时显示，无内容时优雅折叠。
- **第三视觉焦点【长按 800ms 按钮】**：
  - 确认按钮内置 800ms 平滑进度填充：
    - 鼠标按下时，按钮内部以绿色从左向右平滑填满；
    - 达到 800ms 即刻触发发送完成；
    - 中途松开鼠标或滑出按钮，进度立即归零重置。
  - 默认键盘焦点强制落在 `[ 取消发送 (Esc) ]`，防快速连击误发。
- **底部辅助**：
  - 倒计时平滑进度微条与文字（`⏱️ 8.5 秒后自动取消`）。

## 5. 技术实现细节与兼容性保证

1. **WPF 样式体系**：
   - 更新 `App.xaml` 资源，注入完整的全新画刷和统一的 Button、TextBox、ComboBox、CheckBox、ListBoxItem 样式。
2. **逻辑兼容**：
   - 保持所有底层服务接口（`AppServices`、`ContextMonitor`、`AppSettings`、`ProtectedChat` 等）不变，纯重构 View 表现层与 View 级交互。
3. **编译与验证**：
   - 通过 `dotnet build` 验证全部 XAML 编译与 C# 后台逻辑。
